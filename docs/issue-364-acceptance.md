# Criterio de aceptación — Webapp depósito

- Un bloque editable por `LoadOrderProduct`.
- No duplicar el bloque por cantidad de pallets.
- Mostrar cliente, lugar de entrega, producto/presentación, cantidad y pallets relacionados antes de lote/fecha.
- Mantener lote y fecha como únicos campos editables del renglón.
- Mantener el botón de escaneo de lote.
- Mostrar mercadería suelta cuando corresponda.
